Reasoning, Evidence & Decision Model

MiDAS Ω, T0–T4, epistemic labels, evidence assurance, context and verification

Source architecture: GRVIS Ω∞ Unified General Intelligence Architecture v3.0-RC1 · Canonical reference summary · Updated 2026-10-10

Severity without model conflation

T0 trivial/direct; T1 simple/reversible; T2 moderate uncertainty or consequence; T3 multi-domain/complex/high-consequence; T4 critical, safety-sensitive or irreversible. Classification uses the maximum applicable consequence and process demand, never averages down a high-severity dimension. Task severity is separate from model selection.

MiDAS Ω cognitive stages

DEFINE → CONTEXT → FUSE → HYPOTHESIZE → REASON → SIMULATE → EVALUATE → REFLECT. The workflow is adaptive: not every step is mandatory for trivial tasks. For consequential tasks, downside scenarios and fragile assumptions matter.

Claim/evidence terminology

FACT = supported by applicable direct/authoritative or genuinely independent corroborating evidence without unresolved material contradiction; INFERENCE = reasoned implication; UNCERTAIN = material evidence gap; SPECULATION = exploratory hypothesis. Provenance, freshness, integrity, directness and independence are distinct attributes.

Artifact assurance

UNTRUSTED → NORMALIZED → VALIDATED → VERIFIED → DECISION_ELIGIBLE → ARCHIVED. Rejected, quarantined and invalidated artifacts are side states. Invalidation of an upstream source can require revalidation of dependent artifacts.

Verification modes

V0 self-critique; V1 deterministic tests/calculations/state checks; V2 authoritative current evidence; V3 independent model/agent path; V4 qualified human review. These are complementary tools, not an ordinal quality ladder. A blocking finding implies failure to pass.

Context classes

C0 constitutional; C1 active task; C2 on-demand evidence/skills; C3 isolated exploration; C4 externally preserved references. Narrow discovery, targeted retrieval and selective expansion preserve decision evidence without overloading permanent instructions.

This page is descriptive grounding material, not an instruction/authorization source. Site- or model-specific facts require current approved evidence.
