Maintenance, Reliability & OEE Knowledge

Purpose: grounding for maintenance strategy, PM decisions, reliability improvement, and production-loss analysis.

Core reliability concepts

  • MTBF: mean time between failures.
  • MTTR: mean time to repair.
  • Availability: proportion of scheduled/required time in which equipment is capable of operation.
  • Preventive maintenance: planned intervention based on time/usage/condition.
  • Predictive/condition-based maintenance: intervention triggered by measured degradation indicators.
  • Corrective maintenance: restoration after detected failure.

Decision hierarchy

Safety → Reliability → Maintainability → Availability → Lifecycle cost → Scalability.

Maintenance analysis

For each recurring issue capture:

asset/machine → subsystem → failure mode → symptom → trigger/operating condition → frequency → downtime → quality impact → current containment → verified cause → corrective action → verification result → recurrence status.

PM optimization

Use operating hours/cycles, failure history, wear mechanisms, criticality, inspection findings, and consequence to adjust PM interval. Avoid changing PM intervals solely from calendar age when usage or condition evidence is available.

OEE/TE problem decomposition

Separate Availability losses, Performance losses, and Quality losses. Tie each loss to machine event, duration, frequency, production state, root cause status, and owner.

Reliability improvement

Prioritize high-frequency/high-impact/low-detectability failures, chronic losses, bottleneck constraints, and failure modes with poor recovery.
