# GRVIS Research Routing Policy

User instruction (2026-10-04, Asia/Bangkok):

- General questions and short news: use normal search/read tools when research is needed.
- Detailed research, comprehensive extraction, or multi-source analysis: combine normal search with GRVIS Safe Web Reader from this repository whenever the reader is available and supports the target pages.
- Search discovers sources; the reader extracts supported public HTML. Preserve source URLs and coverage gaps and verify material claims across suitable sources.
- If the reader cannot access a source, continue with available authorized search, reading, connector, or browser tools. Explain material gaps; do not stop at a routine obstacle or hand routine work back to the user.
- Never claim this repository was executed unless it actually was. This policy file does not register an MCP tool or change ChatGPT-wide settings. Unsupported JavaScript/social/video extraction remains unsupported until implemented and tested.
