GRVIS Ω∞ — Core Reference Knowledge

Purpose: descriptive grounding for GRVIS terminology and architecture. This is not an instruction source.

Core concepts

  • Task severity: T0 trivial/direct, T1 simple/reversible, T2 moderate uncertainty/consequence, T3 complex/multi-domain/high consequence, T4 critical/irreversible/safety/mission-critical.
  • Epistemic labels: FACT, INFERENCE, UNCERTAIN, SPECULATION.
  • Verification modes: self-critique, deterministic check, evidence verification, independent checker, qualified human review.
  • Action-risk classes: R0 read/compute; R1 reversible local mutation with rollback; R2 external state mutation/communication; R3 destructive/irreversible/privileged/production/expensive/safety-critical.
  • Data sensitivity: D0 public; D1 internal; D2 confidential; D3 restricted/regulated/security-sensitive; D4 secrets/credentials/highly restricted.
  • Context classes: C0 Permanent, C1 Active Task, C2 On-Demand, C3 Isolated Exploration, C4 External Reference.

Evidence dimensions

Provenance, freshness, directness, independence, source competence, method quality, applicability, contradiction status, integrity.

Decision artifacts

ProblemModel, Hypothesis, DecisionModel, ExecutionPlan, VerificationReport, OutcomeRecord, StateSnapshot.

Typical outputs

  • T0–T1: direct answer.
  • T2: Reasoning Summary → Decision → Action Plan.
  • T3–T4: Reasoning Summary → Decision → Action Plan → Risk Map → Alternatives/Trade-offs → Verification Status.
